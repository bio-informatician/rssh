# Rakhssh Chat for iOS (SwiftUI & PWA)

این پروژه شامل پیاده‌سازی کامل کلاینت چت رخش (Rakhssh Chat) برای سیستم‌عامل **iOS (آیفون و آیپد)** است که به دو روش زیر قابل استفاده و استقرار می‌باشد:

---

## 🍏 روش اول: نصب فوری از طریق PWA (بدون نیاز به مک، کامپایل یا اپل آی‌دی)
بهینه‌ترین و سریع‌ترین روش برای استفاده روی تمام مدل‌های آیفون و آیپد:
1. در آیفون، مرورگر **Safari** را باز کنید.
2. آدرس سرور چت خود را وارد کنید:
   - از طریق اینترنت / سرور VPS: `http://<SERVER_IP>:8765`
   - از طریق شبکه محلی Wi-Fi: `http://192.168.1.X:8765`
3. دکمه **اشتراک‌گذاری (Share Icon ⎋)** در نوار پایین مرورگر سافاری را بزنید.
4. گزینه **«Add to Home Screen» (افزودن به صفحه اصلی)** را لمس کنید.
5. دکمه **Add** را در بالای صفحه بزنید.

> ✨ **ویژگی‌های نسخه PWA در آیفون:**
> * دارای آیکون اختصاصی باکیفیت و متاتگ‌های Native iOS.
> * اجرای تمام‌صفحه (Standalone) بدون نوار آدرس سافاری دقیقاً مشابه یک اپلیکیشن بومی.
> * پشتیبانی از حاشیه‌های امنیتی آیفون (Safe Area برای Dynamic Island و Home Indicator).
> * اتصال پایدار به وب‌سوکت با بازگشت خودکار پس از خروج و ورود مجدد.

---

## 📱 روش دوم: پروژه کامل بومی Swift / SwiftUI (کد نیتیو برای Xcode و ساخت IPA)

پروژه کامل بومی با زبان **Swift 5** و فریم‌ورک مدرن **SwiftUI** پیاده‌سازی شده و از `URLSessionWebSocketTask` استفاده می‌کند.

### مشخصات فنی:
* **حداقل نسخه iOS:** iOS 15.0 به بالا
* **پروتکل ارتباطی:** RFC 6455 WebSocket Native Client
* **تنظیمات شبکه (Info.plist):** پشتیبانی از `NSAllowsArbitraryLoads` جهت اتصال به سرورهای محلی `ws://` بدون نیاز به SSL
* **امکانات:** ویبره و فیدبک لمسی (Haptic Feedback)، تغییر سریع سرور، شناسایی وضعیت اتصال، مدیریت خودکار Reconnect

### ساختار فایل‌ها:
```
ios/
├── RakhsshChat.xcodeproj/     # فایل پروژه استاندارد Xcode
│   └── project.pbxproj
├── RakhsshChat/
│   ├── RakhsshChatApp.swift   # نقطه ورود برنامه (@main)
│   ├── ContentView.swift      # رابط کاربری چت و صفحات تنظیمات
│   ├── ChatViewModel.swift    # مدیریت وب‌سوکت، پیام‌ها و استیت‌ها
│   ├── Info.plist             # پیکربندی دسترسی‌های شبکه
│   └── Assets.xcassets/       # آیکون‌ها و رنگ‌های اختصاصی
└── .github/workflows/
    └── build-ios.yml          # ورک‌فلو ساخت خودکار IPA در GitHub Actions
```

### نحوه بیلد و اجرا در Xcode:
1. پوشه `RakhsshChat.xcodeproj` را در نرم‌افزار Xcode (روی سیستم‌عامل macOS) باز کنید.
2. آیفون خود را با کابل به مک وصل کنید (یا یک Simulator انتخاب کنید).
3. در تنظیمات Signing & Capabilities، تیم توسعه یا اپل آی‌دی رایگان خود را انتخاب کنید.
4. دکمه **Run (⌘ + R)** را بزنید تا برنامه مستقیماً روی گوشی نصب و اجرا شود.

---

## ☁️ ساخت فایل IPA بدون مک (از طریق GitHub Actions)
اگر سیستم مک در اختیار ندارید، فایل ورک‌فلو آماده `.github/workflows/build-ios.yml` داخل پروژه قرار داده شده است:
1. این ریپازیتوری را در اکانت گیت‌هاب خود Push کنید.
2. وارد تب **Actions** شوید و ورک‌فلو **Build iOS App (IPA)** را اجرا کنید.
3. گیت‌هاب روی سرور رایگان macOS پروژه را کامپایل کرده و فایل `RakhsshChat.ipa` را در قالب Artifact در اختیارتان قرار می‌دهد.
4. فایل IPA را می‌توانید با ابزارهایی مانند **AltStore**, **Sideloadly**, **Scarlet** یا **TrollStore** روی آیفون نصب کنید.
