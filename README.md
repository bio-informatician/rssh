# Rakhssh Chat (Android + Server)

کلاینت اندروید فوق‌سبک و ماژولار چت با امکان اتصال به هر سرور چت دلخواه (WebSocket یا HTTP) همراه با سرور آماده پایتون و اسکریپت نصب خودکار برای لینوکس اوبونتو.

---

## 📱 مشخصات فایل اندروید (APK)
* **نام فایل:** `chat.apk` (مسیر: `~/agent-work/chat.apk`)
* **نام پکیج:** `org.rssh.chat`
* **نسخه:** `1.0.0`
* **حجم فایل APK:** حدود `۲۵ کیلوبایت` (فوق‌العاده سبک، سریع و کم‌مصرف)
* **پشتیبانی سیستم‌عامل:** اندروید ۸.۰ تا اندروید ۱۴ (API 26-34)
* **مجوزها:** فقط دسترسی به شبکه اینترنت (`INTERNET` / `ACCESS_NETWORK_STATE`) و ویبره (`VIBRATE`)
* **امنیت و ترافیک:** پشتیبانی از ترافیک Cleartext (`ws://` و `http://`) برای اتصال بدون دردسر به سرورهای محلی (LAN) و VPS بدون نیاز به سرتیفیکیت SSL.

---

## 🚀 نصب و راه‌اندازی ۱۰۰٪ خودکار روی سرور لینوکس (Ubuntu)

فایل نصب مستقل `install.sh` همه‌چیز را خودکار انجام می‌دهد:
1. بررسی و نصب پیش‌نیازها (`python3`, `curl`, `ufw`).
2. ساخت کاربر سیستمی مجزا (`chatserver`) برای حداکثر امنیت.
3. استقرار کدهای سرور و وب در مسیر `/opt/chat-server`.
4. ساخت، فعال‌سازی و استارت سرویس دائمی لینوکس (`systemd: chat-server.service`).
5. باز کردن پورت `8765` در فایروال UFW به صورت خودکار.
6. بررسی سلامت اتصال داخلی و نمایش آدرس دقیق جهت اتصال از گوشی.

### اجرای نصب:
فایل `install.sh` را به سرور لینوکس خود منتقل کنید و با دستور زیر اجرا کنید:
```bash
sudo bash install.sh
```

### گزینه‌های پیشرفته:
```bash
# نصب روی پورت دلخواه (مثلاً 9000):
sudo bash install.sh --port 9000

# حذف کامل سرویس و فایل‌ها از سرور:
sudo bash install.sh --uninstall
```

## 📱 نحوه اتصال با اپلیکیشن اندروید
1. فایل `chat.apk` را روی گوشی نصب کنید.
2. اپلیکیشن را باز کرده و دکمه تنظیمات (چرخ‌دنده ⚙️) را بزنید.
3. در قسمت آدرس سرور، آدرس IP سرور خود را با پورت 8765 وارد کنید:
   - اتصال اینترنتی / سرور مجازی: `ws://<SERVER_IP>:8765`
   - اتصال از طریق شبکه محلی وای‌فای: `ws://192.168.1.X:8765`
4. نام دلخواه خود را وارد کرده و دکمه **«اتصال به سرور»** را لمس کنید.

## 🌐 استفاده از مرورگر (Web Client)
علاوه بر برنامه اندروید، می‌توانید با مرورگر گوشی یا کامپیوتر نیز مستقیماً به محیط چت متصل شوید:
```
http://<SERVER_IP>:8765
```

## 🛠️ دستورات مدیریت سرویس روی سرور
* مشاهده وضعیت: `sudo systemctl status chat-server`
* مشاهده زنده پیام‌ها و لاگ‌ها: `sudo journalctl -u chat-server -f`
* ری‌استارت سرور: `sudo systemctl restart chat-server`
* توقف موقت: `sudo systemctl stop chat-server`
