# Rakhssh Web SSH Server & Client (`ssh-web-client`)

Lightweight, zero-dependency browser-based Web Terminal and WebSocket SSH Gateway for Rakhssh.
Listens on port 8766 (completely independent from the chat server on 8765).

## Features
- In-browser interactive terminal powered by xterm.js
- Real-time PTY terminal session multiplexing
- Daemon control via `service.sh`
